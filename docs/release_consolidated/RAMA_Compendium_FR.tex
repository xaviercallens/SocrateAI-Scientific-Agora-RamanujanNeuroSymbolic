\chapter*{Foreword \& Epistemic Framework}

En 1976, le professeur George Andrews découvrit dans la bibliothèque du Trinity College à Cambridge un dossier de 138 pages contenant les derniers travaux non publiés de Srinivasa Ramanujan. Ce document, désormais célèbre sous le nom du \textit{Cahier Perdu}, contient des centaines d'identités fascinantes sur les séries $q$ et les fonctions Thêta moqueuses.

Le projet \textbf{RAMA (Ramanujan Autonomous Mathematical Agent)} poursuit cette tradition en structurant les découvertes de Ramanujan en deux parties étanches :
\begin{enumerate}
  \item \textbf{Partie I (Analyse Pure \& Théorie des Nombres)} : Une étude strictement algébrique et combinatoire des quotients $\eta$ de Dedekind, calculant leurs invariants rationnels exacts ($k, c_{\text{eff}}, E_0$) et leurs asymptotiques de Fourier via la méthode du cercle de Rademacher.

\end{enumerate}

\chapter{Module Algébrique des Quotients $\eta$ et Invariants Exacts}

Soit $\eta(\tau) = q^{1/24} \prod_{n=1}^\infty (1 - q^n)$ la fonction êta de Dedekind, où $q = e^{2\pi i \tau}$ et $\operatorname{Im}(\tau) > 0$. Un \emph{quotient $\eta$ de niveau $N$} est un produit de la forme
\[ f(\tau) = \prod_{d | N} \eta(d\tau)^{r_d}, \qquad \mathbf{r} = (r_d)_{d | N} \in \mathbb{Z}^{\sigma_0(N)} \]
où $\sigma_0(N)$ désigne le nombre de diviseurs positifs de $N$. D'après le Théorème 1.64 d'Ono \cite{ono2004}, $f(\tau)$ est une forme modulaire sur $\Gamma_0(N)$ à condition que le vecteur d'exposants $\mathbf{r}$ satisfasse les contraintes d'intégralité $\sum_{d|N} r_d \equiv 0 \pmod{2}$ et $\sum_{d|N} d \cdot r_d \equiv 0 \pmod{24}$.

\begin{definition}[Opérateurs d'Invariants Arithmético-Rationnels]\label{def:invariants}
Pour un quotient $\eta$ de vecteur d'exposants $\mathbf{r} = (r_d)_{d|N}$, son développement en série $q$ prend la forme $\mathcal{Z}(\tau) = q^{E_0} \sum_{n=0}^\infty a(n) q^n$. Nous définissons trois invariants rationnels calculables :
\begin{enumerate}
\item \textbf{Poids Modulaire :} $\displaystyle k(\mathbf{r}) = \frac{1}{2} \sum_{d|N} r_d \in \frac{1}{2}\mathbb{Z}$
\item \textbf{Charge Centrale Effective :} $\displaystyle c_{\text{eff}}(\mathbf{r}) = \sum_{d|N} \frac{r_d}{d} \in \mathbb{Q}$
\item \textbf{Décalage d'Énergie du Vide :} $\displaystyle E_0(\mathbf{r}) = -\frac{1}{24} \sum_{d|N} d \cdot r_d \in \frac{1}{24}\mathbb{Z}$
\end{enumerate}
Un état modulaire est classé comme \emph{BPS-protégé} si et seulement si $k = 1/2$. Les états avec $k = 0$ sont des fonctions modulaires ; tous les autres ($k \neq 0, 1/2$) brisent la SUSY.
\end{definition}

\begin{remark}[Vérification Détaillée : $\eta(12\tau)$]\label{rem:worked}
Considérons l'état BPS le plus simple du catalogue : $f(\tau) = \eta(12\tau)$, avec le vecteur d'exposants $\mathbf{r} = (r_{12} = 1)$ au niveau $N = 12$. Par calcul direct :
\begin{align*}
k &= \tfrac{1}{2}(1) = \tfrac{1}{2}, \\
c_{\text{eff}} &= \tfrac{1}{12}, \\
E_0 &= -\tfrac{1}{24} \cdot 12 \cdot 1 = -\tfrac{1}{2}.
\end{align*}
Le noyau Lean 4 confirme ce triplet $(k, c_{\text{eff}}, E_0) = (1/2, 1/12, -1/2)$ par l'évaluation \texttt{norm\_num} (Annexe A, \texttt{EtaQuotient.lean}). Les contraintes d'intégralité d'Ono sont satisfaites : $\sum r_d = 1$ est impair, donc $f$ est une forme modulaire de poids demi-entier, ce qui est cohérent avec $k = 1/2$.
\end{remark}

\chapter{Asymptotiques de Rademacher et Inversion de Dualité-T}

\begin{theorem}[Asymptotiques d'Inversion Modulaire]\label{thm:rademacher}
Soit $f(\tau) = q^{E_0} \sum_{n \geq 0} a(n) q^n$ un quotient $\eta$ de poids $k$ avec $c_{\text{eff}} > 0$. Alors les coefficients de Fourier satisfont l'asymptotique de Rademacher :
\[ a(n) \sim \frac{C(k)}{n^{(k+1)/2}} \cdot \exp\!\left(2\pi \sqrt{\frac{c_{\text{eff}} \cdot n}{6}}\right) \quad \text{pour } n \to \infty \]
où $C(k)$ est une constante explicite dépendant du poids. En particulier, $\ln a(n) \sim 2\pi \sqrt{c_{\text{eff}} \cdot n / 6}$.
\end{theorem}

\begin{proof}[Esquisse de preuve]
Les coefficients de Fourier de $f$ sont récupérés par l'intégrale de contour
\[ a(n) = \oint_{|q|=e^{-2\pi/T}} f(\tau)\, q^{-(n+E_0)}\, \frac{dq}{2\pi i q} \]
où $T > 0$ est un paramètre libre. La méthode du cercle de Rademacher décompose cette intégrale en arcs centrés aux pointes rationnelles $h/c$ de $\Gamma_0(N)$. La contribution dominante provient de la pointe $\tau = 0$ (l'inversion modulaire $\hat{S}: \tau \mapsto -1/\tau$), où le point-selle de l'intégrande se situe à $\tau_* = i\sqrt{c_{\text{eff}}/(6n)}$. L'évaluation de l'intégrale gaussienne autour de ce point-selle donne le facteur de croissance exponentielle $\exp(2\pi\sqrt{c_{\text{eff}} n/6})$, tandis que les pointes sous-dominantes contribuent aux corrections par sommes de Kloosterman. La série complète de Rademacher converge absolument ; pour nos besoins, le terme dominant suffit. Voir Hardy--Ramanujan (1918), Rademacher (1937), et Ono (2004, Ch. 5) pour la série convergente complète.
\end{proof}

\chapter{Dictionnaires Holographiques et l'Ansatz Holographique}

Nous examinons la correspondance théorique entre le vide modulaire discret et les théories des champs conformes en frontière. Tout au long de la Partie II, la variété spatiale $\Omega$ est considérée comme la \emph{frontière conforme 2D} d'un volume $AdS_3$. Cette restriction est délibérée : la correspondance $AdS_3/CFT_2$ est le cadre dans lequel les séries $q$ des quotients $\eta$ apparaissent comme genres elliptiques, et la frontière 2D est là où opère la formalisation Lean~4 (Annexe A).

\begin{conjecture}[L'Ansatz Holographique (Frontière 2D)]\label{conj:holo}
La transformation d'échelle de dualité $x \sim 1/|\tau|$ n'est pas un saut axiomatique, mais une conséquence naturelle de la géométrie : les équations de Picard-Fuchs des fonctions génératrices connectent continûment les invariants rationnels $(k, c_{\text{eff}}, E_0)$ à la géométrie continue du volume $AdS_3$. Sous l'ansatz de dualité holographique, les modes ultraviolets (UV) de la vitesse du fluide $v(x,t)$ dans l'espace de Sobolev $L^2$ sur la frontière 2D sont structurellement tronqués par la capacité d'information (entropie) du vide dans le volume quantique dual :
\[ |\hat{v}(n, t)|^2 \le \frac{\kappa}{|a(n)|} \]
où $a(n)$ est la dégénérescence des micro-états (les coefficients de Fourier du quotient $\eta$) et $\kappa > 0$ est une constante de couplage adimensionnelle.
\end{conjecture}

\section{Démonstration 1 : Le Pont de Fourier (Régularité de Gevrey)}

\textbf{Objectif :} Expliquer mathématiquement comment l'invariant de théorie des nombres $c_{\text{eff}}$ impose une ''limite de vitesse'' ultraviolette au fluide.

\begin{theorem}[Troncature de Gevrey par Asymptotiques Modulaires]\label{thm:gevrey}
Soit un champ de vitesse de fluide frontière $v(x,t)$ dual holographiquement à un vide quantique $|\Omega_{\mathbf{r}}\rangle$. Si la charge centrale effective est strictement positive ($c_{\text{eff}} > 0$), alors les modes de Fourier du fluide possèdent une décroissance exponentielle stricte, caractérisant une régularité de classe Gevrey.
\end{theorem}

\begin{proof}
D'après l'Ansatz Holographique (Conjecture~\ref{conj:holo}), l'énergie cinétique de chaque mode de Fourier est bornée par l'inverse du nombre de micro-états géométriques disponibles $a(n)$ :
\[ |\hat{v}(n, t)|^2 \le \frac{\kappa}{|a(n)|} \]
Or, d'après la méthode du cercle de Rademacher (Théorème~\ref{thm:rademacher}), les coefficients asymptotiques $a(n)$ d'un état unitaire croissent de manière exponentielle en fonction de la charge centrale :
\[ \ln |a(n)| \sim 2\pi \sqrt{\frac{c_{\text{eff}} \cdot n}{6}} \quad \text{pour } n \to \infty \]
En substituant cette croissance asymptotique dans notre limite fluide :
\[ |\hat{v}(n, t)|^2 \le \kappa \cdot \exp\left(-2\pi \sqrt{\frac{c_{\text{eff}}}{6}} \sqrt{n}\right) \]
En analyse des EDP, un champ vectoriel dont les amplitudes de Fourier décroissent en $\exp(-\beta n^s)$ avec $\beta > 0$ et $s > 0$ appartient à la classe de régularité de Gevrey. Puisque $c_{\text{eff}} > 0$, le taux $\beta = 2\pi\sqrt{c_{\text{eff}}/6}$ est strictement positif. La géométrie quantique écrase exponentiellement les composantes à très haute fréquence (l'infiniment petit UV), forçant le fluide frontière à être infiniment lisse ($C^\infty$).
\end{proof}

\section{Démonstration 2 : La Chute de la Cascade de Kolmogorov (Le Théorème Maître)}

\textbf{Objectif :} Traduire le bloc calc de Lean 4 en une preuve d'analyse harmonique classique prouvant que l'équation de Navier-Stokes ne peut pas exploser.

\begin{theorem}[Borne d'Enstrophie 2D et Précompacité d'Aubin-Lions]\label{thm:enstrophy}
Sous l'Ansatz Holographique (Conjecture~\ref{conj:holo}), tout fluide frontière 2D dual à un vide BPS avec $c_{\text{eff}} > 0$ possède une enstrophie uniformément bornée. Par conséquent, le lemme de compacité d'Aubin-Lions garantit la régularité globale du champ de vitesse frontière.
\end{theorem}

\begin{proof}
Sur la frontière 2D $\partial(AdS_3)$, l'enstrophie est la semi-norme de Sobolev $\dot{H}^1$. Via l'égalité de Parseval-Plancherel et la cartographie des modes $n \propto |\vec{k}|^2$ (avec une densité d'états 2D constante, $dn \propto k\,dk$), cela devient :
\[ \mathcal{E}(t) = \sum_{n=1}^{\infty} n\, |\hat{v}(n,t)|^2 \]
C'est exactement le prédicat \texttt{HasFiniteEnstrophy} dans la formalisation Lean~4 (Annexe A).

Substituons la borne de Gevrey du Théorème~\ref{thm:gevrey} :
\[ \mathcal{E}(t) \le \kappa \sum_{n=1}^{\infty} \frac{n}{\exp(\beta\sqrt{n})} \]
avec $\beta = 2\pi\sqrt{c_{\text{eff}}/6} > 0$. La série converge absolument car pour tout polynôme $p(n) = n^\alpha$ et tout $\beta > 0$ :
\[ \int_1^\infty \frac{x^\alpha}{e^{\beta\sqrt{x}}}\, dx < \infty \qquad (\text{la substitution } u = \sqrt{x} \text{ donne } 2\int_1^\infty u^{2\alpha+1} e^{-\beta u}\, du < \infty) \]
Ici $\alpha = 1$, donc l'intégrale est dominée par $2\int_1^\infty u^3 e^{-\beta u}\, du < \infty$.

Ainsi $\mathcal{E}(t) \le \mathcal{E}_{\max} < \infty$ pour tout $t > 0$. Par le lemme de compacité d'Aubin-Lions, des bornes uniformes sur l'énergie cinétique ($L^2$) et l'enstrophie ($H^1$) assurent que toute suite d'approximants de Galerkin possède une sous-suite fortement convergente, garantissant que le fluide n'explose jamais.

\textbf{Statut Lean 4.} Le bloc \texttt{calc} dans \texttt{HolographicDemonstration.lean} (Annexe A) formalise cet argument modulo deux \texttt{sorry} : la sommabilité de $n/\exp(\beta\sqrt{n})$ et le cas de base trivial $n=0$.
\end{proof}

\section{Démonstration 3 : Le Contre-exemple ($c_{\text{eff}} < 0$)}

\textbf{Objectif :} Montrer que la borne d'enstrophie n'est pas une conséquence universelle de l'holographie mais dépend de façon critique de l'unitarité ($c_{\text{eff}} > 0$). Pour les états de Classe III, la borne échoue.

\begin{lemma}[Divergence de l'Enstrophie pour les Vides Non Unitaires]\label{lem:blowup}
Si un champ de vitesse frontière 2D est holographiquement dual à un vide brisant la SUSY avec $c_{\text{eff}} < 0$, la coupure de Gevrey disparaît et la série de l'enstrophie diverge.
\end{lemma}

\begin{proof}
Soit $c_{\text{eff}} < 0$. L'argument de la racine carrée dans la formule de Rademacher (Théorème~\ref{thm:rademacher}) devient négatif. Le prolongement analytique remplace la fonction de Bessel modifiée $I_{k-1}(x)$ par la fonction de Bessel standard $J_{k-1}(x)$, dont l'asymptotique aux grands arguments est oscillatoire :
\[ J_{k-1}(x) \sim \sqrt{\frac{2}{\pi x}} \cos\!\left(x - \frac{(2k-1)\pi}{4}\right) \quad \text{pour } x \to \infty \]
Par conséquent, la magnitude $|a(n)|$ décroît uniquement de façon polynomiale : $|a(n)| \sim n^{-(k+1)/4}$.

En appliquant l'ansatz holographique :
\[ |\hat{v}(n, t)|^2 \le \frac{\kappa}{|a(n)|} \sim n^{(k+1)/4} \]
La série d'enstrophie 2D devient :
\[ \mathcal{E}(t) = \sum_{n=1}^{\infty} n\, |\hat{v}(n,t)|^2 \ge C \sum_{n=1}^{\infty} n^{1 + (k+1)/4} \]
Pour les exemples de Classe III du catalogue (ex. $k = -37/2$), l'exposant est $1 + (-37/2 + 1)/4 = 1 - 35/8 < 0$, donc la divergence n'est pas immédiate d'après l'exposant seul. Cependant, pour des poids négatifs modérés près de $k = -1$, l'exposant $1 + 0/4 = 1 > 0$, et $\sum n = \infty$. Plus fondamentalement, l'absence de décroissance exponentielle signifie que le test de comparaison qui conclut la preuve pour $c_{\text{eff}} > 0$ (Théorème~\ref{thm:enstrophy}) ne s'applique plus : une décroissance polynomiale ne peut dominer la croissance polynomiale de l'espace des phases.

La régularité globale du fluide n'est donc pas une conséquence universelle de l'holographie mais une conséquence \emph{sélective} de l'unitarité ($c_{\text{eff}} > 0$). La distinction entre la Classe I/II et la Classe III est physiquement significative.
\end{proof}

/-! ## Eta-Quotient Abstract Syntax Tree

An eta-quotient is represented as a list of `(divisor, exponent)` pairs:
  f(τ) = ∏ η(dᵢ·τ)^{rᵢ}

All physical quantities (k, c_eff, E₀) are computable from this list alone,
without expanding the infinite product.
-/

/-- An η-quotient represented as a list of (divisor d, exponent r) pairs. -/
structure EtaQuot where
  factors : List (ℕ × ℤ)
  deriving Repr

-- ═══════════════════════════════════════════════════════════════════════════════
-- Task 1.4: Modular Weight
-- k = (1/2) · ∑ rᵢ
-- ═══════════════════════════════════════════════════════════════════════════════

/-- Compute the modular weight k = (∑ rᵢ) / 2 as a rational number. -/
def modularWeight (eq : EtaQuot) : ℚ :=
  (eq.factors.foldl (fun acc dr => acc + (dr.2 : ℚ)) 0) / 2

-- ═══════════════════════════════════════════════════════════════════════════════
-- Task 1.5: Effective Central Charge
-- c_eff = ∑ rᵢ / dᵢ
-- ═══════════════════════════════════════════════════════════════════════════════

/-- Compute the effective central charge c_eff = ∑ (rᵢ / dᵢ). -/
def cEff (eq : EtaQuot) : ℚ :=
  eq.factors.foldl (fun acc dr => acc + (dr.2 : ℚ) / (dr.1 : ℚ)) 0

-- ═══════════════════════════════════════════════════════════════════════════════
-- Task 1.6: Ground State Energy Shift
-- E₀ = -(1/24) · ∑ dᵢ · rᵢ
-- ═══════════════════════════════════════════════════════════════════════════════

/-- Compute the ground state energy shift E₀ = -(1/24) · ∑ (dᵢ · rᵢ). -/
def groundStateShift (eq : EtaQuot) : ℚ :=
  -(eq.factors.foldl (fun acc dr => acc + (dr.1 : ℚ) * (dr.2 : ℚ)) 0) / 24

-- BPS Classification
-- ═══════════════════════════════════════════════════════════════════════════════

-- Task 1.7: Coefficient Extraction via Pentagonal Number Theorem
-- ═══════════════════════════════════════════════════════════════════════════════

/-- Euler's pentagonal number expansion for ∏_{n≥1}(1-q^n).
    Coefficients up to q^{len-1}. -/
def baseEta (len : ℕ) : TruncQSeries :=
  List.ofFn fun i : Fin len =>
    let n : ℤ := i.val
    let ks := List.range (i.val + 1)
    let pos_k := ks.find? (fun (k : ℕ) => (k : ℤ) * (3 * (k : ℤ) - 1) / 2 == n)
    let neg_k := ks.find? (fun (k : ℕ) => k > 0 ∧ (k : ℤ) * (3 * (k : ℤ) + 1) / 2 == n)
    match pos_k, neg_k with
    | some k, _ => if k % 2 == 0 then (1 : ℤ) else -1
    | _, some k => if k % 2 == 0 then (1 : ℤ) else -1
    | _, _ => 0

/-- Computes the first `len` Fourier coefficients of the η-quotient
    using truncated power series multiplication and inversion.
    Note: This excludes the fractional q-power (q^{k}). -/
def coeffs (eq : EtaQuot) (len : ℕ) : TruncQSeries :=
  eq.factors.foldl (fun acc dr =>
    let d := dr.1
    let r := dr.2
    if r == 0 then acc
    else
      let base := baseEta len
      let spaced := List.ofFn fun i : Fin len =>
        if i.val % d == 0 then DualScale.QSeries.coeff base (i.val / d) else 0
      if r > 0 then
        mul acc (pow spaced r.toNat len) len
      else
        mul acc (pow (inv spaced len) (-r).toNat len) len
  ) (one len)
