## The two that matter most

**`dualscale/lean/DualScale/Physics/AubinLions.lean`** axiomatises the type, the
observable, the *conclusion predicate*, and the *implication*, then proves a
theorem by applying the axiom:

```lean
axiom aubin_lions_compactness (S : Set VelocityField) : Prop   -- the conclusion
axiom aubin_lions_apply … : aubin_lions_compactness S          -- the implication

theorem aubin_lions_enstrophy_compactness … : aubin_lions_compactness S := by
  exact aubin_lions_apply h_ens_bound h_ke_bound               -- the proof IS the axiom
```

Because `aubin_lions_compactness` has no definition the theorem asserts nothing
falsifiable, and because `VelocityField` has no exhibited inhabitant the
hypotheses may be vacuous. This is what **R3** is about.

**`NAMAGIRI.lean`** (repository root, imported by nothing, in no lakefile — so it
contaminates no build):

## Suggested order

1. **Land this PR.** Report-only, so nothing breaks, and the number stops being
   able to grow silently.
2. **Label `NAMAGIRI.lean`** — a header marking it a non-gated sketch. Cheapest
   fix, zero risk, removes the sharpest reading.
3. **Convert axioms to hypothesis parameters**, file by file, verifying the build
   after each. This *preserves* the work: the theorems survive, become explicitly
   conditional, and the dependency becomes visible in the type instead of
   invisible in the footprint. Do not delete them — they encode roadmap intent.
4. **Re-tier what the conversion exposes.** Results with published backing are
   Tier L, not axioms: `rogers_ramanujan_identity` is a famous theorem entered as
   an assumption.
5. **Remove `--report-only`** when the count reaches zero.
